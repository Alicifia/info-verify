# 七维检验清单（详细版）

> 配合 SKILL.md 使用。对每条原子断言逐维打分：每维输出 ✅ 通过 / ⚠️ 有疑点 / ❌ 不通过 / — 不适用。

## 维度 1：来源（信息从哪里来）

**检验问题**

- 是一手来源（当事人、官方、原始论文）还是 N 手转述（媒体→自媒体→群聊）？
- 发布者是谁？在该领域有无资质与既往信誉（专家发言域、机构职能）？
- 有无利益动机：带货、立场先行、引流、公关稿、付费推广？
- 时效：信息产生于何时？是否已被更新/撤回/更正？

**红旗信号**

- "据网传 / 据知情人士 / 据说"——无可核查来源
- 转述链条超过 2 层且原始出处缺失
- 发布者恰好从你相信它中获益
- 截图无 URL、无日期、无上下文
- 来源是"平行来源"假象：10 篇文章其实都转自同一篇通稿

**绿旗信号**

- 一手来源可直接访问（官方公告、论文 DOI、原始数据集）
- 发布者有该领域的 track record 且无利益相关
- 文内自带方法论与数据披露

## 维度 2：边界（适用于什么范围）

**检验问题**

- 原文明确限定了哪些条件？时间、地域、人群、样本量、前提假设？
- 传播中被去掉或泛化了哪些限定词？
- 结论的因果方向是"相关"还是"因果"？是"个案"还是"统计规律"？

**红旗信号**

- "某地试点 → 传成全国推行"、"动物实验 → 传成人体验有效"
- "研究发现"不交代样本（n=?、谁、哪里、多久）
- 把相关说成因果、把个案说成普遍
- 老数据被当作现况引用（"最新研究"实为 2018 年）

**绿旗信号**

- 原文自带限制声明（limitations）
- 适用条件在转述中被完整保留

## 维度 3：验证（能否交叉印证）

**检验问题**

- 有无**相互独立**的第二来源？（独立性 = 不同的原始信源，不是互相转载）
- 反向搜索：用关键词 + 反方立场检索，看有没有证伪报道？
- 证据链能否闭合：从结论回溯到原始证据，每一环都存在吗？

**实操方法**

- 正向：提取断言中的关键实体/数字/日期，WebSearch 检索
- 反向：检索"关键词 + 辟谣/更正/造假/争议"
- 定域：官方站点、监管公告、原始论文数据库优先于新闻聚合
- 图片类：反向搜图验证是否移花接木、旧图新用

**红旗信号**

- 全网只有同一通稿的 N 个变体
- 关键数字在不同来源间对不上，且无一方解释差异
- "独家/内部消息"且无法复核

## 维度 4：完整性（是否被截取）

**检验问题**

- 引文是否有下文/上文被裁掉而改变原意（断章取义）？
- 统计是否缺分母（"80% 的人支持"——多少人的调查？谁被调查？）
- 是否缺关键限定：时间、对照、条件、例外情况？

**红旗信号**

- 惊人的百分比没有基数
- 一句话引语找不到完整语境
- 数据只有结果没有口径（统计年份、指标定义、名义/实际）

## 维度 5：自洽性（内部逻辑）

**检验问题**

- 断言之间有无矛盾？（同一文章里前后数字打架）
- 与基础常识/物理/已确认事实有无冲突？
- 推理是否成立：前提能推出结论吗，还是只是"听起来有道理"？

**红旗信号**

- 数量级异常（未经说明的 10 倍以上偏离常识值）
- 因果倒置、幸存者偏差、诉诸个案

## 维度 6：数字口径

**检验问题**

- 单位（万/亿、美元/人民币、名义/实际、同比/环比）是否明确？
- 分母是什么？口径变化过吗（统计范围调整）？
- 增长率有无低基数效应？

**实操**：找到原始统计发布页核对口径定义；数量级 sanity check。

## 维度 7：动机分析（谁受益）

**检验问题**

- 这条信息被传播，谁获益？（流量、销量、立场、恐慌/安抚）
- 传播节奏是否像营销（时间点配合发布/上架）？
- 是否在利用情绪（愤怒、恐惧、焦虑传播最快）？

**红旗信号**

- 标题情绪浓度远高于信息浓度
- 唯一的"解决方案"恰好指向发布者的产品/账号

# 定级与折算规则

- 七维中有任一核心维（来源/边界/验证）❌ → 该断言不高于 C
- 验证维无独立第二来源 → 最高 B
- 存在可靠反证 → D（证伪）
- 查不到 ≠ 假 → C 或 E（不可证），措辞上必须区分"未发现证据"与"证据显示不实"
- **总评 ≠ 各断言评级的简单最低值**：取核心断言（支撑主结论的那几条）的最低评级，并在总评中说明理由

# 实战案例

## 案例 1：新闻转述类

待检验："网传 X 市 2026 年起全面禁售燃油车。"

1. 拆解：①X 市出台禁售政策 ②2026 年起 ③全面（所有车型/所有区域）
2. 三问：来源为"网传"，无原始文件 → 检索发现 X 市发改委确有征求意见稿，但仅针对**中心城区新增网约车**，时间为 2026 年起。
3. 定级：①B（有官方文件但仍是征求意见稿，非正式政策）②A ③D（"全面"被证伪）
4. 边界：适用于中心城区新增网约车，不涉及存量私家车、非中心城区。
5. 总评：**C —— 政策文件存在，但范围被严重泛化，"全面禁售"为不实转述。**

## 案例 2：数据引用类

待检验："某报告称该行业市场规模已达千亿。"

- 数字口径：是产值、GMV 还是融资额？统计年份？名义值还是增速换算值？
- 边界：报告样本是否只覆盖头部企业？"千亿"是预测还是已发生？
- 若报告来自该行业协会 → 动机维 ⚠️（行业倾向放大利好）→ 标注"单一利益相关来源，建议找第三方数据对照"。

## 案例 3：AI 交付自检

即将输出"某框架的性能比另一框架高 30%"前自检：

- 来源：数字出自某篇基准测试博客，仅为单一环境、单一版本的测试
- 边界：仅在特定硬件与负载下成立，不能泛化为普遍性能结论
- 验证：检索到另一独立测试，数值差异较大且环境不同

→ 处理：输出时改写为"在 [来源] 的 [具体环境] 测试中高出约 30%，不同环境结果差异较大（另一测试为 X%），建议以自身场景实测为准"。
