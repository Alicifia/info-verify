# info-verify-skill

一个给 AI Agent 使用的**信息检验技能**：对任何信息（新闻、数据、传闻、AI 输出、报告、转述、截图）进行"来源 / 边界 / 验证"三维检验，判定其**完整性、正确性与可用性**。

## 核心理念

> **完整 ≠ 正确 ≠ 可用。** 信息齐全不代表属实，属实不代表适用于你的场景。
> **AI 越强，独立判断越值钱。**

完整性、正确性、可用性是三个**独立**的质量维度。本技能的目标不是简单回答"真假"，而是给出**分层结论 + 适用边界 + 证据链**。

## 工作流（五步）

1. **拆解**：把待检验信息拆成最小可验证断言（3~8 条），区分事实断言 / 观点断言 / 推测断言
2. **三问检验**：来源（谁说的、凭什么、图什么）→ 边界（适用范围有无被泛化）→ 验证（能否交叉印证）；辅以完整性、自洽性、数字口径、动机分析四维，共七维清单
3. **五级定级**：A 已证实 / B 大概率属实 / C 存疑 / D 已证伪 / E 不可证
4. **边界标注**：对属实信息生成"时间 / 地域 / 人群 / 条件"适用范围卡，"正确但被误用"的信息单独标边界警告
5. **输出报告**：结论先行 + 断言级证据表 + 反证与存疑点 + 引用建议

## 关键纪律

- **事实性断言必须现查**：用 WebSearch / WebFetch 检索独立来源，禁止仅凭训练记忆对事实定级
- **评级必有证据链**：给不出可检索出处的一律不高于 C
- **查不到 ≠ 是假的**：区分"证伪"与"未验证"
- **AI 红队三问**：交付含关键事实/数据/引文的内容前，自检来源、边界、验证三维

## 安装

把整个文件夹（含 `SKILL.md`）放入你的技能目录即可：

- Kimi Work / Kimi CLI：`<skills-root>/info-verify/SKILL.md`
- Claude Code 兼容路径：`~/.config/agents/skills/info-verify/` 或 `~/.claude/skills/info-verify/`

## 使用

安装后对 AI 说自然语言即可触发：

- "这个说法靠谱吗？"
- "帮我查一下这条新闻是不是真的"
- "这个数据可信吗？是不是缺口径？"
- "这段转述有没有断章取义？"
- 也可在 AI 交付含关键事实的结论前要求它跑一次自检

详细七维评分细则、红旗/绿旗信号与实战案例见 `references/checklist.md`。

## 适用范围

- 目标：新闻、数据、传闻、AI 输出、报告、转述、截图等任何待检验信息
- 价值：既适用于主动核实单条信息，也适用于 AI 交付结论前的自查环节

## 免责

本技能提供的是检验方法与置信度分级，不构成对任何信息的最终背书；定级结论以检验时可获得的证据为准。
